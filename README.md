# Logic Builder

A game where you build circuits out of primitive logic gates and make new blocks out of them.

## Sandbox Mode

Build freely with no limits. You can choose which gates to start with when creating a new project.

## Puzzle Mode

Complete challenges by building a circuit that does what the puzzle requires using limited amount of logic gates. You can load expansion pack .json files to add more puzzles. Those packs are also saved automatically once loaded.

## Saves

Everything is automatically saved to your browser. You can export your projects and puzzle progress as .json files to import in a different browser or share with friends.
